# Путь Шиноби (The World of Shinobi)

Visual Novel на Godot 4.7  
Разрешение: **1024 × 768**

## Как запустить

1. Открой проект в **Godot 4.7**
2. Нажми F5

## Что есть сейчас

### Экраны
- **Главное меню** — старт, карта, энциклопедия, карточки, выход
- **Игровой экран** (vn_scene) — визуальная новелла с диалогами и выбором
- **Карта сюжета** — список глав (Пролог, 1-1, 1-2...)
- **Нарутопедия** — энциклопедия (заготовка)
- **Карточки шиноби** — коллекция персонажей (заготовка)

### Геймплей
- Простая система диалогов
- 3 ветки выбора в прологе
- Безликие болванки вместо спрайтов

## Управление в игре

- **Пробел / Enter / ЛКМ** — дальше
- Кнопки выбора — клик
