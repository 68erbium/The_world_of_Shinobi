# The World of Shinobi

Visual Novel на Godot 4.7  
Пролог / MVP

## Как запустить

1. Скачай/открой проект в **Godot 4.7**
2. Открой папку репозитория
3. Нажми F5 (или Play)

## Что есть сейчас

- Главное меню
- Простая система диалогов (без внешних плагинов)
- Выбор из 3 вариантов
- 3 короткие ветки пролога
- Безликие болванки вместо персонажей (ColorRect)

## Управление

- **Пробел / Enter / ЛКМ** — дальше
- Кнопки выбора — клик

## Структура

```
scenes/
  main_menu.tscn
  vn_scene.tscn
scripts/
  main_menu.gd
  vn_scene.gd
```

## Планы

- Полноценный сюжет во вселенной Наруто
- Нормальные спрайты и фоны
- Больше персонажей и веток
- Возможный переход на Dialogic 2
